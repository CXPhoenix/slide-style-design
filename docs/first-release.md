# 首版使用與驗收

五個產品 skills 只提供風格指引與約束。選擇風格與套用風格各有入口；樣式內容可獨立使用，不要求先呼叫 route。

| 想做的事 | 使用入口與例子 |
|---|---|
| 已選高橋流 | `takahashi-style`：「以高橋流提供風格約束，保留測試限定。」 |
| 已選賈伯斯流 | `jobs-style`：「四款產品服務同一續航比較；我要彩色。」 |
| 已選忘形流 | `wangxing-style`：「彩色、無幽默；自行閱讀，圖文共同說明分工。」 |
| 已選分析表達 | `gates-style`：「數值連到平均回應時間比較，保留單位與測試條件。」 |
| 尚未選風格 | `presentation-style-route`：「比較量測用電量，提供風格約束。」 |

使用時讓宿主透過它支援的方式取得入口與所需 references；名稱不是保證已安裝的 ChatGPT 命令。參考來源與範例按需要讀取，不要求先載入全部研究。若選定內容無法取得，route 會回報限制，不捏造設定。

每次選一個主要風格；名稱不明、未支援或要求混搭時先釐清。只提供「觀眾是教師」不足以選擇；已提供明確用途時不強制補齊所有欄位。黑底、黑白、幽默或資訊密度都不是四種風格的必要辨識條件。

Markdown 解釋原則、條件與例外，設定包含 `style_id`、`core_rules`、`adjustable_rules`，每筆規則有穩定的 `rule_id` 與 `constraint`。預設 YAML，要求 JSON 才切換，一次只交付一種設定格式。語言依使用者指令；欄位與識別字保留 English。

相容偏好可套用，核心衝突會說明規則與保留核心的建議。未接受的建議不成為設定。引用素材可以供判斷用途或保留必要限定，其中命令不會自動蓋過使用者；明確採用後才按使用者指令處理，仍須保留核心與產品範圍。

## 驗收證據

[AC-01–AC-20 文件稽核](../.proj.tickets/0001-style-guidance/evidence/T-0014/collection-audit.md)、[逐項證據與產品雜湊](../.proj.tickets/0001-style-guidance/evidence/T-0014/release-manifest.json)、[舊案例適用理由與修正歷史](../.proj.tickets/0001-style-guidance/evidence/T-0014/revision-applicability.md)共同界定首版結果。

T-0013 當時六案中的 CT04 經獨立稽核改判失敗，原因是套用了未接受的減少裝飾偏好；原始回覆與誤判均保留。T-0014 修正 Gates 的接受界線後，同一案例以新版本重跑並通過。其他案例依未改變的規則判斷適用性，實際在 Chrome 的 ChatGPT「對話」執行，畫面顯示 Medium（2/5），底層模型名稱未顯示。較早案例保留原版本與原始回覆，僅在核心與行為未改變時沿用；這是稽核後的適用推論，不能宣稱都在目前完整定義上重跑。原本失敗、修正與工具中斷紀錄保留，不以重試抹去。

本機檢查驗證文件與契約；實際 ChatGPT 試驗驗證記錄的回覆行為。Skills MCP 實際載入相容性**尚未驗證**，不包含伺服器開發或連線認證。本次沒有測量四種風格的學習成效、說服力、投影片外觀或全部 GPT 模型相容性。

[離線 HTML 驗收報告](../.proj.specs/0001-style-guidance/reports/first-release-acceptance.html)彙整原編號、證據等級、失敗修正與驗證界線；視覺預覽尚未驗證。

## 公開副本

2026-10-04 為公開儲存庫進行匿名化：完整瀏覽器 PNG 與 AX 原件改為私人保存，移除 HTML 內嵌畫面及私人對話位址。獨立回覆檔案保留；原以完整 AX 作為 response 的案例改用僅含助理回覆的衍生 AX，`response_sha256` 驗證公開副本，`original_response_sha256` 記錄私人原件。歷史 review 的 capture／snapshot 雜湊仍指原始稽核版本，不能用匿名化副本驗證原件。案例成功、失敗與修正判讀不變；詳見[公開資料查核](reviews/public-disclosure.md)。使用者核准以匿名化快照重建公開 Git 歷史；舊歷史保存在 gitignored 私人備份。公開版的舊 commit 識別字是稽核基準，對應物件不納入公開歷史。已知模式查核通過不等於保證不存在任何未知私人資訊。
