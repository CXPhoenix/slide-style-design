## 忘形流核心指引

本風格指的是**張忘形**；`wangxing` 是此專案的風格識別字，不代表創作者的官方英文名稱。

本次應遵循核心規則 `wangxing.text_visual_relation`：

- 文字觀點應維持精簡，但必須完整保留限定條件：**「在這個團隊中，清楚說明分工，有助減少重複工作」**。不可省略「在這個團隊中」，以免把特定情境下的觀點擴張成普遍結論。
- 既有的「相連任務區塊 → 各人的分工」圖像，應與文字共同表達**分工如何被清楚界定**這個關係。讀者看到任務區塊與人員的對應，即能理解各項工作由誰負責，以及工作邊界如何被區分。
- 圖像的功能不只是裝飾。它應協助讀者理解文字中的因果關係：**分工被具體呈現 → 工作責任較容易辨識 → 有助減少團隊中的重複工作**。若圖像無法呈現任務與人員之間的對應關係，即使版面美觀，也不符合此核心。
- 此素材為**自行閱讀的彩色社群圖文**，因此不能依賴講者口頭補充。文字、任務區塊、人員對應，以及「限於這個團隊」的條件，都應從圖文本身即可理解。
- **彩色與不使用幽默均不影響忘形流核心。**此處重點不是黑白、迷因或特定視覺形式，而是精簡觀點與圖像之間具有可辨識、且確實幫助理解的對應關係。

```yaml
style_id: wangxing
core_rules:
  - rule_id: wangxing.text_visual_relation
    constraint: >-
      讓精簡觀點文字與既有的相連任務區塊圖像共同表達同一觀點或明確關係。
      必須保留「在這個團隊中」的限定，不將觀點泛化；圖像應透過任務區塊與各人
      分工的對應，協助讀者理解清楚界定工作責任如何有助減少重複工作，而非僅作
      裝飾。由於素材供讀者自行閱讀，觀點、圖文對應關係及必要限定都必須能在沒有
      講者補充的情況下理解。彩色及不使用幽默不妨礙此核心。
adjustable_rules: []
```
