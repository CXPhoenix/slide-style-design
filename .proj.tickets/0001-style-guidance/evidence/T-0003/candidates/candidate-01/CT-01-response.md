## 比爾蓋茲流：現場投影簡報風格指引

這裡的「比爾蓋茲流」指的是 **Bill Gates-inspired analytical style**。核心不是「塞很多數字」或「每頁都放圖表」，而是讓觀眾在投影環境下，能迅速看懂：

**這個證據支持什麼？這些數字在比較什麼？這些系統元件彼此怎麼影響？**

核心規則為 `gates.evidence_relation`。

### 現場投影時的表達原則

**1. 每頁先有一個分析重點，再放證據。**  
不要只投影「42%」「1.8×」「128 GB」等孤立數字。頁面應先清楚指出比較或系統重點，再讓數據成為證據。例如：

> 「增加記憶體不等於線性增加多人推論容量」

接著才呈現並行人數、VRAM／Unified Memory、模型大小、KV cache 或實測 throughput。

**2. 圖表要讓人看得出「比較關係」，而不只是看得到資料。**  
現場投影宜優先使用：
- A / B 對照
- before / after
- 不同方案的同尺度比較
- 因果鏈或系統關係圖
- 少量但明確標註的趨勢圖

圖表旁可直接標出結論，例如「16 users 時開始出現 throughput bottleneck」，比要求觀眾自己從 8 條線中找答案更適合投影。

**3. 單位、條件與測試前提不能為了簡潔而刪除。**  
例如比較：

**125 tokens/s vs. 78 tokens/s**

至少必須保留足以解釋它的條件，例如：
- tokens/s 是總 throughput 還是 per-user throughput
- concurrent users = 16
- model / quantization
- context length
- 是否使用相同測試工作負載

若這些資訊決定結論是否成立，就屬於簡報內容本身，不是可有可無的附註。

**4. 現場投影降低「閱讀負擔」，但不降低「分析完整性」。**  
可以把詳細資料放到 appendix，但主頁仍需保留理解結論必要的資訊。適合的結構通常是：

**結論 → 關鍵證據 → 必要條件**

而不是：

**大量資料 → 大量資料 → 大量資料 → 最後才說結論**

**5. 系統架構圖必須表達關係。**  
如果是 AI、資安、網路或資訊系統簡報，不宜只是排列：
`Agent / LLM / Tool / Sandbox / Target`

應標示實際關係，例如：

`Student → Agent → Tool execution → Isolated sandbox → Target`

再透過箭頭、邊界、信任區域或資料流說明：「學生不能直接接觸 Target」這個系統重點。

**6. 視覺層級應服務於證據閱讀順序。**  
投影時可形成三層：
- **第一層：分析結論**——遠處就能看到。
- **第二層：關鍵數字／圖表／系統關係**——支撐結論。
- **第三層：單位、條件、來源、限制**——需要時可以讀到。

因此，比爾蓋茲流不等於「字很小、資訊很多」。即使一頁很留白，只要證據與結論的關係清楚，仍符合核心。

### 適合現場投影的版面傾向

標題最好直接陳述分析觀點，而不是只有主題名稱。例如：

- 較弱：**Inference Performance**
- 較佳：**16 人同時使用後，瓶頸從模型載入轉向 KV Cache 與吞吐量**

如果是比較頁，可採：

**上方：一句結論**  
**中間：主要圖表或 A/B 比較**  
**下方：2–4 個必要條件／限定**

如果是系統頁，可採：

**左側：系統圖**  
**右側：系統重點與風險／瓶頸**  

但左右兩側必須是在解釋同一個分析問題，而不是兩組互不相關的資訊。

### 不建議的誤用

不應把這個風格理解為：
- 每頁都要有很多數據。
- 圖表愈多愈好。
- 所有證據都必須擠在同一頁。
- 不可以說故事、幽默或做 demonstration。
- 有數字就自然變成分析型簡報。

真正不可省略的是：**證據與分析主張之間可被理解的關係。**

這套規則是依據 Gates 的分析取向與公開演講材料所做的專案式綜整，不是 Bill Gates 官方公布的簡報方法或固定格式。

```yaml
style_id: gates
core_rules:
  - rule_id: gates.evidence_relation
    constraint: >-
      現場投影時，讓證據、數量或系統元件明確連到一個已陳述的比較或系統重點，
      使觀眾能直接理解證據支持什麼、正在比較什麼，或系統元件如何彼此關聯。
      使用清楚的視覺層級與必要註記強化此關係；若標籤、單位、測試條件、
      假設或適用範圍對解讀既有證據不可或缺，必須保留，不得為了精簡、
      留白或放大字體而刪除。現場投影可以降低單頁閱讀負擔、拆分詳細資料
      或減少裝飾，但不得破壞證據與分析重點之間的關係；高資訊密度並非必要條件。
adjustable_rules: []
```
